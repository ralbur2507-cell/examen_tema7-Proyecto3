# ID-Gen Pro - Examen Tema 3

Aplicación desarrollada con Python y Streamlit para generar credenciales corporativas personalizadas.

## Funcionalidades
- Introducir nombre, cargo y número de empleado.
- Seleccionar el color de la marca.
- Subir una fotografía.
- Visualizar la credencial.
- Descargar la credencial en formato PNG.

## Tecnologías utilizadas
- Python
- Streamlit
- Pillow

## Ejecución
streamlit run Examen_tema3.py
